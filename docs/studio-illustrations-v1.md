# Studio illustrations V1 — candidate graphics, not new knowledge

Execution: #264 / draft #263. Baseline before graphics: `2a99b1f`. Workbench preparation is not a graphics pass.

## Candidate artwork

Six existing activities receive sixteen explicit vector states: day (4), lion growth (3), water (2 reused in opposite directions), germination (3), and the original supervised visit story (4). One lazy renderer composes reusable scenery, a lion rig, a consistent bowl, soil/plant parts, station/engine/adult primitives and the existing canonical Dheu character. The renderer owns no learning order, answers, storage, navigation or audio.

Day uses the same landscape, horizon and small rise/set motion symbols, not an orbital diagram, fixed clock hours or equal-daylight assertion. Night deliberately does not require a visible Moon. The lion family is a single illustrative female growth example, not an age scale or a rule that adults have manes. The water pair retains one vessel and has no heating flame, boiling bubbles or volume labels. Plant pictures are illustrative soil cutaways, not a timed growth simulation. The visit remains fiction, not emergency training.

All artwork is draft. Visual plausibility and reference validity do not establish factual entailment or human/editorial approval. No canonical graph schema or claim is changed.

## Source binding

`content/experience/studio-scene-bindings.json` contains question/source references and unordered item-to-appearance bindings guarded by exact source text. The shared build decorator adds only `visualRefs`. It cannot replace labels, order, solution, knowledge refs, concepts, revision or evidence policy. Missing/stale/sparse/duplicate bindings and changed source wording fail closed. A source edit requires another illustration review; it is not silently treated as cosmetic.

The existing visual registry admits these candidates only by explicit reference. Neither general semantic lookup nor label inference can select them. The normal visual validation gate rejects candidate illustrations in assessing questions and rejects unreachable artwork.

## Interaction and motion

Source labels remain adjacent and authoritative. Motion is limited to short, one-shot settling of a leaf/tail/ripple; it never moves to the next learning stage. Reduced-motion presentation is static. Landscape, bowl and whole scene do not bob indefinitely. Dheu's reusable persona is kept static inside story cards. No inline asset IDs, external resources, timers, sound, flashing, correctness marks or automatic advancement are introduced.

## Evidence

Implementation and new regression tests are committed before observed CI results. Subsequent entries in #264 record exact-head results and visual findings. Geometry tests are not human aesthetic or child-use approval. Physical-device and real-child review remain open.
